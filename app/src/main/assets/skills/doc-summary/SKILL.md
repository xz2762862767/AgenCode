# 长文摘要

## 三层结构
1. **一句话结论**：不超过 40 字，说清这篇东西到底讲了什么、什么立场
2. **要点**：3-6 条，每条一行，只留论证与数据，删掉铺垫
3. **可执行项**：原文里的建议、待办、风险提示（没有就写「无」）

## 规则
- 优先保留数字、时间、结论性判断，删掉举例与修辞
- 不添加原文没有的观点，不评价好坏，除非用户要求
- 原文有矛盾或数据打架时，单独列「需要注意」
- 长文超 8000 字时，先给目录式概要，再展开要点

## 输出格式
```
**结论**：...

**要点**
- ...

**可行动项**
- ...
```

## 结尾
需要引用原文时，标出所在段落，不复制整段。
