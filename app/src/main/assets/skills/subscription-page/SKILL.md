# 会员订阅页

目标不是「好看」，是让人看懂值不值，然后决定。

## 页面骨架（自上而下）

1. **价值句**：一句话说清买了能得到什么
2. **核心权益**：3-5 条，每条一行，带图标
3. **价格卡**：2-3 档，默认选中推荐档
4. **权益对比表**：免费 vs 会员
5. **常见问题**：3-5 条，专门打掉犹豫
6. **底部 CTA** + 自动续费说明

顺序别乱。价值没讲清就摆价格，用户只会记住「要收钱」。

## 文案原则

- **说省多少，不说多少钱**：「每天 0.3 元」比「98 元/年」感受轻得多
- **给锚点**：年卡旁边标「相当于 5 折」，让用户自己算出划算
- **数字具体**：「1200+ 模板，每周更新」远胜「海量模板」
- **免费档要有真价值**，否则用户连带不信付费档
- **别造假的紧迫感**：假倒计时、假库存短期能提转化，退款率和差评长期更贵

价值句改写示例：
- ❌「尊享会员，畅享全部特权」
- ✅「把每周的报告工作从 3 小时压到 20 分钟」

## 价格卡规范

- 2-3 档为宜，超过三档选择困难
- 推荐档：描边高亮 + 角标「最受欢迎」+ 默认选中
- 每档只写三行：**价格 / 折算单价 / 一句差异点**
- 并列时年卡放最右（视线终点），月卡在最左
- 价格不写小数（`.00` 没意义还占宽度）

## 权益对比表

- 只放 5-8 行，别堆 20 条凑数
- 表头：`功能 | 免费 | 会员`
- 用 ✓ / — 表示，不写长句子
- 差异化功能放最上面，基础功能垫底

## 合规（必须写进页面，不是可选）

- **自动续费**：明示扣费周期、金额、随时可取消、取消的具体路径
- **试用**：写清试用天数、到期自动扣费、如何提前取消
- **退款政策**：给可点的链接，别只在协议里藏着
- 国内需符合《网络交易监督管理办法》对自动续费的显著提示要求
- Google Play：订阅必须走 Play Billing，不得引导站外支付

## 输出格式

给用户交付四样东西，不要只给抽象建议：

1. **结构骨架**（每块占多大比重）
2. **可直接粘贴的文案**（每块的标题、正文、按钮文字都写全）
3. **视觉规范**（字号层级、留白、强调色只用在推荐档和 CTA 上）
4. **合规清单**（上面四条逐条落实在哪一句）

## 反面案例（遇到直接指出来）

- 权益列表 15 条，一半是「专属客服」这类无感项
- 三个档位价格逻辑混乱，年卡反而比月卡贵
- 页面全是「立即开通」，却不回答「能解决我什么问题」
- 默认勾选自动续费且字小到看不见
