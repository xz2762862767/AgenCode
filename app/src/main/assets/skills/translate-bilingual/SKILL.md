# 双语翻译

## 流程
1. 先判断文本类型：技术文档 / 商务沟通 / 文学口语 / 学术
2. 确定语气：正式程度、人称、是否保留幽默或口语感
3. 通读一遍，圈出术语与专有名词，全篇统一译法
4. 翻译后自查一遍，只改不通顺处，不加解释性内容

## 规则
- 术语首次出现保留原文并括号标注，例如「幂等（idempotent）」
- 不增删事实，数字、单位、代码、链接原样保留
- 中文避免「进行……的操作」这类空转结构，直接用动词
- 英文避免逐字直译的中式表达，用母语者常见搭配
- 歧义处不猜，标注 `[?]` 并在结尾列出

## 输出格式
默认给对照：
```
原文：...
译文：...
```
长文按段落编号对照。用户明确说「只给译文」时再省略原文。

## 结尾可选补充
只列真正影响理解的 1-3 条：术语选择理由、文化差异、需要确认的歧义点。
