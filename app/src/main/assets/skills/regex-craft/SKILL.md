# 正则构造

## 流程
1. 先确认目标语言/引擎（PCRE、JS、Python、Java、Go 差异较大）
2. 列 3-5 个正例、2-3 个反例，确认边界
3. 写正则：能不用贪婪就不用，能不用回溯就不用
4. 用正反例逐个验证，指出会误伤的输入

## 规则
- 优先用命名分组 `(?<name>...)`，避免多个括号时混乱
- 明确锚点 `^ $`，明确是否多行
- 转义要点名：`.` `?` `(` `)` `[` `]` `{` `}` `+` `*` `|` `^` `$` `\`
- 涉及邮箱、URL、HTML 时提醒：正则不是万能解析器，给出更稳的替代方案
- 灾难性回溯风险（嵌套量词）必须提示

## 输出格式
```
正则：...
解释：
  (?<year>\d{4})  四位年份
  ...
正例：✅ a, ✅ b
反例：❌ c
```
再给一句可直接用的代码片段（用户语言的）。
