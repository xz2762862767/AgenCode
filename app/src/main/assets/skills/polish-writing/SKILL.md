# 文字润色

## 顺序
1. 先删：副词、重复修饰、无信息量的开场句（「众所周知」「随着……的发展」）
2. 再拆：一句话只讲一个意思，超过 40 字的长句拆开
3. 再换：把名词化结构换回动词（「对数据进行处理」→「处理数据」）
4. 最后调：段落顺序、逻辑连接词

## 硬约束
- 不改事实、数字、专有名词、引用原话
- 不擅自扩写，篇幅只能持平或更短
- 保留作者的语气与立场，不要改成公文腔

## 输出格式
```
【成稿】
<润色后的完整文字>

【改动说明】
- 原句 → 改后：原因（最多 4 条）
```

用户只想要结果时，就直接给成稿，末尾一行说「共改 5 处」。
