# 会议纪要

## 输出结构
1. **会议信息**：主题、时间、参与人（缺失就写「未提及」）
2. **已达成决议**：每条写明「决定了什么」，不加讨论过程
3. **待办清单**：表格形式 —— 事项 / 责任人 / 截止时间 / 状态
4. **遗留问题**：没结论的话题，写清分歧点与下一步
5. **下次会议**：时间与议题（有则写）

## 整理规则
- 转写稿里的口头语、重复、跑题内容全部剔除
- 责任人只写记录里明确提到的，不推测
- 时间含糊的（「下周」「尽快」）原样保留，并标 `[待确认]`
- 同一个人前后说法不一致时，两条都留，标 `[有分歧]`

## 格式
```
## 待办
| 事项 | 责任人 | 截止 | 状态 |
|---|---|---|---|
| ... | ... | ... | 待开始 |
```

## 提醒
纪要只记录，不评价；需要用户确认的地方集中列在最后，最多 5 条。
