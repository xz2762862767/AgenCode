# 周报生成

## 核心原则
流水账写「做了什么」，周报写「做成了什么、影响了谁、下一步」。

## 结构
1. **本周产出**：3-5 条，每条格式「动作 + 结果 + 量化影响」
   例：完成订单接口重构，P99 从 800ms 降到 210ms
2. **进行中**：当前进度百分比 + 预计完成时间
3. **问题与风险**：需要上级或跨部门支持的事，写清要谁做什么
4. **下周计划**：3 条以内，可验证

## 改写规则
- 「参与了」「协助了」这类词换成具体贡献
- 没有量化数据时，用可观察的结果替代（上线了、评审通过、缺陷清零）
- 不夸大：没上线的不写「已完成」，写「已开发完成，待测试」
- 每条不超过两行，删掉技术细节，除非读者是同行

## 输出
直接给可粘贴的周报正文，不要额外解释。末尾附一行「建议补充的数据：...」。
